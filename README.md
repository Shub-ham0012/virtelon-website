# Virtelon — Website

Marketing website for **Virtelon Private Limited** — a founder-led software & AI studio.
Static site (HTML/CSS/JS), no build step.

## Pages
- `index.html` — home + Solutions / Industries / Work / Products / Company (client-side routing)
- `tools.html` — Free Tools hub
- `whatsapp-tool.html` — WhatsApp link & QR generator
- `roi-calculator.html` — Missed-lead cost calculator

## Deploy
Any static host. On Netlify: connect this repo (publish directory = root) or drag the folder to app.netlify.com/drop.
